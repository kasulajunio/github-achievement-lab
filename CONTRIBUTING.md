# Checklist de contribuição

Antes de abrir uma pull request:

- [ ] A mudança resolve uma necessidade descrita.
- [ ] O texto está claro e revisado.
- [ ] A alteração foi feita em uma branch própria.
- [ ] A descrição da pull request explica o impacto.

Obrigado por ajudar a manter o histórico do projeto útil e fácil de revisar.
