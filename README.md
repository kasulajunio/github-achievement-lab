# GitHub Achievement Lab

Um laboratório público para praticar contribuições pequenas, claras e úteis no GitHub.

## Como começar

1. Leia a documentação do projeto.
2. Faça uma melhoria objetiva em uma branch.
3. Abra uma pull request explicando a mudança.
4. Revise o conteúdo antes de mesclar.

## Princípios

- Mudanças pequenas e rastreáveis
- Histórico de commits compreensível
- Documentação como parte do produto
