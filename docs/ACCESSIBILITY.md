# Guia de acessibilidade

## Checklist básico

- Use títulos em ordem lógica.
- Descreva imagens e controles de forma objetiva.
- Não dependa apenas de cor para comunicar estado.
- Escreva links com contexto suficiente.
- Prefira linguagem simples e instruções diretas.

A acessibilidade deve ser revisada junto com conteúdo e funcionalidade.
