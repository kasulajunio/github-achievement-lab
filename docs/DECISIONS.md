# Registro de Decisoes

## Como usar

Registre decisoes que alterem direcao, manutencao ou contribuicao. Cada registro deve incluir contexto, escolha, consequencias e data.

## DEC-001: Mudancas pequenas e revisaveis

**Contexto:** este repositorio serve de laboratorio publico de contribuicoes.

**Decisao:** preferir pull requests com um objetivo concreto e escopo limitado.

**Consequencias:** a revisao fica mais clara e a reversao de uma mudanca e mais segura.
