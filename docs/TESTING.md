# Guia de testes

## Antes de mesclar

1. Confirme que o problema foi compreendido.
2. Teste o fluxo alterado no ambiente disponível.
3. Verifique links, arquivos e instruções adicionadas.
4. Registre limites conhecidos na pull request.

## Resultado esperado

Uma alteração deve ser pequena, verificável e fácil de reverter se necessário.
